<h1>SourNexZ Audio Player</h1>

<h3>A whole new robust Media player able to play any Media formats existed in the whole world. </h3>
It can play wav,aiff,dsd,au,snd,pcm,flac,alac,wma,ape,wv,tta,shn,dolby true hd,mp3,aac,ogg,opus,wma,MPC,atrac. So just open the app ,let the app scan the local storage, and listen. This app contains a lyrics sync if you got the .vtt file for the song, enjoy listening to your hits, audio recordings, call recordings, whatsapp audios, anything you can think of. 

This app contains a custom Equalizer, you can use that Equalizer to change the audio settings, bass boosting. 
It contains 3 example songs there. So can test them if you want.
